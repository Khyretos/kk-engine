# BUGS.md — Kreative Kompas Engine bug tracker

**Read this before starting any debugging session, and before saying "this
works" about anything below.** This file exists because bugs were getting
rediscovered across sessions — a fix landed in one module, the same root
cause resurfaced in a sibling module weeks later, and nothing pointed back
to the original fix or explained why. `README.md`'s own "Known
simplifications" section had already gone stale in-session (it still
claimed RmlUi image loading was "a stub" hours after that was fixed, and
claimed resize handling was fully verified before a real panel-scaling bug
was found in that exact area) — a long narrative changelog is not a
substitute for a queryable table. This is that table.

## How to use this file

- **Before fixing a bug, search this file for the symptom, the file, or
  the general area first.** If it's listed as Fixed, the bug you're
  looking at is either a regression (worth its own new entry linking
  back) or a *different* bug with a similar symptom — don't assume
  it's already handled just because something with this name exists.
- **When you fix a bug, add or update its row here in the same
  session**, not as a follow-up. Include enough in "Root cause" and
  "Fix" that someone (human or AI) hitting a similar symptom in a
  *different* module can recognize the same pattern without re-deriving
  it from scratch.
- **When you find a bug you don't fix yet**, add it anyway with
  Status = Open. An accurately-described open bug is more valuable
  than a silent gap.
- IDs are `BUG-NNN`, assigned sequentially, never reused even if a bug
  turns out to be invalid — so a stale reference in old commit messages
  or old conversation history still resolves to the right row.
- "Session" is the rough chronological point this was found, for
  cross-referencing against README's own "Immediate next slices"
  history if the fuller narrative is ever needed. Not a hard date.

| BUG-025 | RmlUi / MaterialGridModule, LightingControlsModule shutdown | Every demo using these panels segfaulted on exit (exit code 139), including clean window-close and the scripted benchmark's quit. | Use-after-free. | BUG-026 | Physics / PhysicsModule fracture rendering | After an object fractured, most of its pieces were invisible or flickered — a shattered Glass Sheet looked like a few stray shards. | The fracturable render path uploaded *each* piece's vertices to offset 0 of the same buffer and recorded one draw per piece. | BUG-028 | Physics / sleeping | Physics cost never went down once things stopped moving — after 15 s of simulated time ~480 of 491 debris pieces were still simulated, though ~95% were moving under 0.05 m/s. | Two causes stacked.
